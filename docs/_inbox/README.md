# _inbox — material crudo

> **Actualizado:** 2026-09-18 · **Estado:** estable

Aquí va **tal cual** lo que nos llega sin procesar: PDFs y slides del track, capturas,
transcripciones de charlas con mentores de HappyRobot, exports de la plataforma, enlaces
en bruto.

## Cómo nombrar

`YYYY-MM-DD-origen-tema.ext`

Ejemplos:
- `2026-09-18-happyrobot-brief-track.pdf`
- `2026-09-18-happyrobot-slides-kickoff.pdf`
- `2026-09-18-mentor-jorge-notas-llamada.md`
- `2026-09-19-plataforma-captura-workflow-editor.png`

## Regla

Todo lo que entre aquí debe acabar **destilado** en un documento de `docs/` (con fuente
apuntando al fichero del inbox). El inbox es el archivo histórico, no la fuente de
consulta.
